# T4: RAG Fundamentals

Microwave-manual assistance using LangChain, FAISS, and EPAM DIAL. Retrieval selects manual chunks, augmentation combines them with the question, and generation is instructed to use only that context.

## Source

- Course: <https://github.com/epam/ai-applications-development-from-api-to-agents>
- Task: `t4_rag_fundamentals` (Python).
- The course's `microwave_manual.txt` is bundled in `solution/t4_rag_fundamentals/`, so the solution does not require the workspace clone. Use `--manual /path/to/microwave_manual.txt` to select another copy.

## Provider: EPAM DIAL

Load the root environment without printing its values:

```bash
set -a; source .env; set +a
```

Only `OPENAI_BASE_URL`, `OPENAI_MODEL`, and `OPENAI_API_KEY` are required. Chat uses the configured model. Embedding discovery prefers deployment IDs beginning with `text-embedding`, then other non-vision embedding IDs, with alphabetical ordering within each group; use `--embedding-model <deployment>` to override this heuristic. No additional model environment variable is required. Both clients send `Api-Key` headers; public OpenAI hosts are rejected.

## How to Run (`uv run`)

Run from the repository root after loading `.env`. All dependencies are provided through `uv run --with`, following T2's pattern.

### All Course Examples With Captured Output

```bash
mkdir -p app_development/t4-rag-fundamentals/output
set -o pipefail
uv run --with langchain-community --with langchain-openai \
  --with langchain-text-splitters --with faiss-cpu \
  --directory app_development/t4-rag-fundamentals/solution \
  python -u -m t4_rag_fundamentals.app --all --k 8 \
  2>&1 | tee app_development/t4-rag-fundamentals/output/rag_examples.txt
```

The transcript includes retrieval scores, selected chunks, augmented prompts, and actual model responses. `pipefail` preserves a failing Python exit code rather than reporting only `tee` success. Generated output is local and ignored by Git. This command uses `--k 8` because the default four chunks omitted the initial clock-setting step in the observed run.

### One Question

```bash
uv run --with langchain-community --with langchain-openai \
  --with langchain-text-splitters --with faiss-cpu \
  --directory app_development/t4-rag-fundamentals/solution \
  python -u -m t4_rag_fundamentals.app \
  --query "What is the ECO function on this microwave and how do you activate it?"
```

Omit `--query`/`--all` for interactive mode; enter `quit` or `exit`, or send EOF, to stop. Increase `--k` to experiment with more context; `--score` must be between 0 and 1.

### Offline Tests

```bash
uv run --with pytest --with langchain-community --with langchain-openai \
  --with langchain-text-splitters --with faiss-cpu \
  --directory app_development/t4-rag-fundamentals/solution \
  python -m pytest t4_rag_fundamentals/test_t4_rag.py -v
```

FAISS caches are stored beside the manual under `microwave_faiss_index/`, keyed by manual content, embedding deployment, and chunk configuration. Generated caches and output are ignored by Git. Documents use JSON rather than pickle. Load only trusted local indexes. An explicit `--index-dir` is caller-managed: choose a fresh directory when changing the manual or embedding model.

## Results / Notes

Verified on 2026-10-20: **17 offline tests passed** in both the course fork and final solution. The live run used the chat deployment configured in `.env` and discovered `text-embedding-005`; neither deployment name is hard-coded in the implementation.

The final seven-example run used `--k 8 --score 0.3` and loaded the existing 104-chunk FAISS index:

| Question | Observed response |
| --- | --- |
| Maximum cooking time | 95 minutes. |
| Set the clock | All five steps, beginning with holding POWER/CLOCK for 3 seconds to choose the clock format. |
| ECO function | Power saving; select ECO using DISINFECT/DEODORIZE/ECO and MENU/TIME, then confirm with START/QUICK START. |
| Smoking containers | Switch off or unplug; keep the door closed. |
| Remove odors | A cup of water with juice and skin of one lemon; microwave for 5 minutes, then wipe and dry. |
| DIALX Community | Explicitly states that the supplied context contains no information. |
| Dinosaur era | Explicitly states that the supplied context contains no information. |

Local transcripts: `output/rag_examples.txt` (final run), `output/rag_examples_k4.txt` (initial text-embedding run), and `output/rag_examples_vision_initial.txt` (diagnostic run). Alphabetical-only discovery initially chose vision embeddings and retrieved poor context; text-first discovery fixed that selection. The default `k=4` still retrieved an incomplete clock procedure, so the documented batch command uses `k=8`.

The course-required `langchain-community` dependency currently emits a deprecation notice. Context-only prompts reduce unsupported answers but are not a security guarantee. Short chunks can omit neighboring instructions; inspect the printed context when evaluating answer completeness.
