### 4-1. Septima Ola: Spanish Concert Introduction

[t4/septima_ola_intro.py](t4/septima_ola_intro.py) introduces the reggae/jazz band
**Septima Ola** in Spanish, with `nova` as the default voice, subtle echo, an ocean-like
noise swell, and a quiet cinematic bass background. The effects are synthesized
and mixed locally, not generated by DIAL; no external music files are needed.

Narration (CDMX is expanded for pronunciation):

> ¡Buenas noches, mi gente! Desde Ciudad de México, Valle de Chalco, Coacalco y
> Puerto Rico, llega una ola de ritmo, alma y libertad. El reggae marca el pulso;
> el jazz abre el horizonte. Prepárense para una noche que se vuelve leyenda.
> ¡Con ustedes... Séptima Ola!

Run from the repository root with [uv](https://docs.astral.sh/uv/):

```bash
set -a; source .env; set +a
uv run --with requests --with imageio-ffmpeg \
  --directory app_development/t3-content-generation/solution \
  python -m t3_content_generation.t4.septima_ola_intro
```

The script prefers an installed `ffmpeg` on `PATH`. Otherwise, `imageio-ffmpeg`
supplies its bundled executable on supported platforms, without sudo.
Alternatively, install `requests` and `imageio-ffmpeg` in your Python environment
and run the module from `solution/`.

Optional flags: `--voice onyx` (also `alloy`, `echo`, `fable`, `nova`, `shimmer`)
and `--output-dir /tmp/septima-ola`. Edit `TEXT` in the script to customize the
announcement. Rerunning overwrites the files in the chosen output directory.

#### Optional A2 background

Generate a 30-second stereo A2 (110 Hz) WAV with gentle pulsing and fades.
Run from the repository root using your installed FFmpeg:

```bash
mkdir -p app_development/t3-content-generation/output
ffmpeg -nostdin -hide_banner -loglevel error -y \
  -f lavfi -i "sine=frequency=110:sample_rate=44100:duration=30" \
  -af "tremolo=f=0.5:d=0.35,afade=t=in:d=1,afade=t=out:st=29:d=1" \
  -ac 2 -c:a pcm_s16le \
  app_development/t3-content-generation/output/a2_110hz.wav
```

For the brighter A4 (440 Hz) alternative, also 30 seconds:

```bash
ffmpeg -nostdin -hide_banner -loglevel error -y \
  -f lavfi -i "sine=frequency=440:sample_rate=44100:duration=30" \
  -af "tremolo=f=0.5:d=0.35,afade=t=in:d=1,afade=t=out:st=29:d=1" \
  -ac 2 -c:a pcm_s16le \
  app_development/t3-content-generation/output/a4_440hz.wav
```

The standalone samples last 30 seconds. The mixer still trims or loops them to
the narration length plus four seconds; it does not pad the announcement to 30 seconds.

Use that sample, or another local WAV/MP3, as the optional background while
generating new narration (`nova` by default; requires the exported `.env` above):

```bash
uv run --with requests --with imageio-ffmpeg \
  --directory app_development/t3-content-generation/solution \
  python -m t3_content_generation.t4.septima_ola_intro \
  --background-audio "$PWD/app_development/t3-content-generation/output/a2_110hz.wav" \
  --output-dir ../output/nova-a2
```

The absolute background path avoids ambiguity when `uv --directory` changes
the working directory. A supplied file replaces the synthetic background,
loops or trims to fit, and is normalized to a quiet level with opening/closing
fades. Voice echo remains. Missing, corrupt, or empty audio is rejected before
DIAL is called. Omit `--background-audio` to retain the original synthetic bed.
The Python API also accepts `main(..., background_audio=Path("sample.wav"))`
and `mix_intro(clean, target, ffmpeg, background_audio=Path("sample.wav"))`.

To remix the existing Nova clean recording locally, without a new DIAL request:

```bash
uv run --with requests --with imageio-ffmpeg \
  --directory app_development/t3-content-generation/solution python -c '
from pathlib import Path
import shutil, imageio_ffmpeg
from t3_content_generation.t4.septima_ola_intro import mix_intro
out = Path("../output")
ffmpeg = shutil.which("ffmpeg") or imageio_ffmpeg.get_ffmpeg_exe()
mix_intro(out / "nova/t4_1_septima_ola_clean.mp3", out / "nova/t4_1_septima_ola_A2.mp3", ffmpeg,
          background_audio=out / "a2_110hz.wav")'
```

The remix command requires the earlier Nova clean recording; use the generation
command first if it is absent and adjust paths accordingly. All WAV/MP3 files
remain git-ignored. A2 is a low tone, not a complete reggae/jazz backing track.

Default outputs in `app_development/t3-content-generation/output/` (git-ignored):
- `t4_1_septima_ola.mp3`: final stereo mix with a short opening and effects tail.
- `t4_1_septima_ola_clean.mp3`: unprocessed DIAL narration.
- `t4_1_septima_ola.txt`: narration in UTF-8.
- `t4_1_septima_ola.log`: redacted model attempts and request/response log.

**Model findings (live catalog checked 2026-10-23):** `tts-hd-001` is the best
listed choice for an offline speech recording, with `tts-001` as fallback.
The script honors `OPENAI_MODEL` first, then tries these two candidates, at most
three distinct deployments. No dedicated expressive TTS or music-generation
deployment was found. These TTS models ignore style instructions, so Mexican
wording and Spanish pronunciation are supported by the text, but a Mexican
accent or dramatic announcer delivery is not guaranteed. Listen before live use;
the background is atmosphere, not a reggae/jazz performance.

## Bonus: Gemini Image Generation

Explore Google's image generation capabilities using the Gemini API.

### Gemini Native Image Generation
- [Docs](https://ai.google.dev/gemini-api/docs/image-generation)
- Model: `gemini-2.5-flash-image`
- Endpoint: `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`
- Set `responseModalities: ["TEXT", "IMAGE"]`
- The response contains interleaved text and inline image data (base64)
- Try generating the same `"Smiling catdog"` prompt and compare with OpenAI results

### Imagen 4
- [Docs](https://ai.google.dev/gemini-api/docs/imagen)
- Models: `imagen-4.0-generate-001`, `imagen-4.0-fast-generate-001`, `imagen-4.0-ultra-generate-001`
- Endpoint: `POST https://generativelanguage.googleapis.com/v1beta/models/{model}:predict`
- Key parameters: `numberOfImages` (1–4), `aspectRatio` (1:1, 9:16, 16:9, ...), `personGeneration`
- All generated images include a SynthID watermark
- `GEMINI_API_KEY` is already available in `constants.py`
