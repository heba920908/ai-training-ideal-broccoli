Metric Message Passing Shared State
Coupling Loose (independent agents) Tight (shared dependency)
Latency ~50-200ms (network + serialization) ~5-20ms (local access)
Failure Isolation High (failures stay local) Low (corruption can spread)
Debugging Easier (message trace available) Harder (race conditions possible)
Scalability High (horizontal scaling) Limited (DB bottleneck)
Best For Distributed systems, microservices Single-process, low-latency needs
