Memory Types

Episodic Memory

Specific past events and experiences tied to time and context.

"User asked about pricing on 2024-03-15 → Sent detailed quote"

Semantic Memory

General facts and knowledge independent of personal experience.

"Python 3.12 was released in October 2023"

Procedural Memory

How-to knowledge and learned skills for task execution.

"To deploy: 1) Run tests 2) Build docker 3) Push to registry"
